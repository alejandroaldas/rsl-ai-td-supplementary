# Supplementary material — systematic literature review on AI-induced technical debt

Supplementary data for the submitted article *AI-Induced Technical Debt in Code Generated by
Large Language Models: A Systematic Literature Review Oriented to Its Prevention and
Measurement*. Author information is withheld for double-blind review.

The review follows PRISMA 2020 and the Kitchenham and Charters guidelines. This repository
contains its complete protocol and decision record in a single Excel workbook:

**[`rsl_supplementary_anonymous.xlsx`](rsl_supplementary_anonymous.xlsx)**

| Sheet | Content |
|---|---|
| `README` | Description of the sheets, reason codes, and formulas |
| `S0_PRISMA` | Selection flow of both search arms |
| `S1_Search_strings` | Full Boolean text, topic, date, and per-database counts of strings B1–B13 |
| `S2_Criteria` | Inclusion criteria I1–I14, exclusion criterion E1, and reason codes |
| `S3_Extraction` | Data-extraction matrix of the 36 included studies (18 fields, incl. method and key finding) |
| `S4a_Screening_main` | Decision log of the 141 records screened in the main search (B1–B10) |
| `S4b_Screening_compl` | Decision log of the 15 records screened in the directed complementary search (B11–B13) |
| `S5_Quality` | Quality-assessment scores (QA1–QA6), total, and band of the 36 included studies |

## Selection flow

| Stage | Main (B1–B10) | Complementary (B11–B13) |
|---|---:|---:|
| Records identified (Scopus + IEEE Xplore) | 437 | 35 |
| Duplicates removed | 296 | 20 |
| Records screened (title/abstract) | 141 | 15 |
| Reports assessed at full text | 41 | 6 |
| **Studies included** | **32** | **4** |

Total studies in the synthesis: **36**.

## Notes

- Some cells are formulas (totals, quality bands, and links between sheets); they are computed
  when the workbook is opened in Excel or LibreOffice.
- Abstracts and raw reviewer notes from the screening tool are not redistributed; each
  screening decision carries a reason code and a short rationale instead.
